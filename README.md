# 咲く・散る — Generative Flower

一輪の花が蕾から開き、満開を迎え、花びらが一枚ずつ風に散り、また蕾に還る。
幾何学的な対称性（秩序）が、散っていく花びら（混沌）へ移り、再び秩序に戻る循環を、ひとつの位相 φ ∈ [0, 1) で描く WebGL 作品です。

### ▶ 作品を見る

**https://york-14.github.io/Generative-Flower/**

ブラウザで開くだけで動きます（PC・スマートフォン対応、外部ライブラリなし）。

[![咲く・散る](docs/og.jpg)](https://york-14.github.io/Generative-Flower/)

## 一周の流れ

| 蕾 | 開花 | 満開 | 散る | 余韻と再生 |
|:-:|:-:|:-:|:-:|:-:|
| ![蕾](docs/phase-1-bud.jpg) | ![開花](docs/phase-2-open.jpg) | ![満開](docs/phase-3-bloom.jpg) | ![散る](docs/phase-4-scatter.jpg) | ![余韻と再生](docs/phase-5-return.jpg) |
| φ 0.00–0.20 | 0.20–0.45 | 0.45–0.60 | 0.60–0.85 | 0.85–1.00 |
| 閉じた花びらが呼吸するように揺れる | 外側の層から順に開く | 対称性が最も高い状態 | 花びらが順に離れ、やがて乱れて舞う | 次の蕾が中心から育つ |

φ = 0 と φ = 1 の描画は画素単位で一致し、継ぎ目なくループします。

## 操作

| 操作 | 内容 |
|---|---|
| 花びらの数 N | 5〜12 枚 |
| 拡散長 λ | 中心の紅色がどこまで広がるか |
| カオスの強さ | 散る相でのロジスティック写像の r の最大値（3.5〜4.0） |
| 周期 T | 一周にかかる秒数（6〜40 秒） |
| 位相 φ | ドラッグで好きな瞬間へ移動 |
| 再生／一時停止 | スペースキーでも切り替え |
| 別の花を生成 | 色（桜・白梅・桃・藤・紅梅）と花びらの形を変える |
| 隠す／操作 | パネルを消して全画面で眺める |

URL の末尾に指定すると、その状態から始まります。

- `?phi=0.5&paused` … 満開で停止
- `?seed=3` … 3 番目の花

OS の「視差効果を減らす（prefers-reduced-motion）」が有効なときは、満開で停止した状態から始まります。

## しくみ

すべての描画は φ の閉じた式で決まり、時間の逐次積分を使いません。そのため位相をスクラブしても同じ絵が正確に再現されます。

1. **極座標のセル分割**　花の中心を原点に、角度方向を N 個のセルに分けます。花びらの外形は
   `r(θ) = R(φ) · |cos(N(θ − θᵢ) / 2w)|^k` に、先端の切れ込みを加えたものです。花びらは 3 層で、内側の層は π/N 回転し、少し遅れて開きます。セルの境界は、重なった花びらの柔らかい影として現れます。
2. **モルフォゲン拡散と閾値応答**　中心からの濃度 `c = exp(−r/λ)` に閾値を当てて、雄しべの金色 → 付け根の紅 → 淡い花色 → 縁の透け、と色を切り替えます。
3. **領域の歪み**　`q = p + ε · w(p, φ)`。ε は満開でほぼ 0、散る相で大きくなり、残った花も崩れていきます。
4. **閉曲線に沿ったノイズ**　w はノイズ空間の円周上でサンプリングするので、φ = 0 と φ = 1 で同じ値になります。
5. **ロジスティック写像による秩序から混沌へ**　花びらごとに `x ← r·x(1 − x)` を反復します。r は 2.9（安定）から最大 3.95（カオス）まで上がるため、最初は順番どおりに離れた花びらが、周期倍化を経てばらばらのタイミングと回転で散っていきます。
6. **散る花びら**　最大 200 枚のクアッドとして描き、位置は
   `p(τ) = p₀ + v₀τ + ½gτ² + A · curlNoise(p₀, τ)`（τ は離脱からの経過）で決めます。回転しながら裏返り、裏面は少し暗くなります。

描画は 2 パスです。パス 1 で花本体をフルスクリーンのフラグメントシェーダで、パス 2 で散る花びらをアルファブレンドで重ねます。WebGL1 のみで動作し、devicePixelRatio は 1.5 に制限しています。

## GitHub Pages の設定（初回のみ）

上の URL で表示されないときは、Pages を有効にしてください。GitHub アプリにはこの設定がないため、ブラウザで行います。

1. ブラウザで https://github.com/York-14/Generative-Flower/settings/pages を開く
2. **Source** を「Deploy from a branch」にする
3. **Branch** を `main`、フォルダを `/ (root)` にして **Save**
4. 1〜2 分後に https://york-14.github.io/Generative-Flower/ で表示されます

ローカルで見るときは、`index.html` をダウンロードしてブラウザで開くだけで動きます。
